# TF2VRFragCooking
This modded file will Re-enable frag grenade cooking for the TF2VR mod. Immediately begins cooking when you grab a frag, and it WILL explode in your hand

# How to install
I modified one file, tf2vr_interactions.gnut. That file lives at this filepath.
### SteamLibrary\steamapps\common\Titanfall2\TF2VR\mods\Titanfall2VR.Cockpit\mod\scripts\vscripts

Go there and replace the interactions file with the file in this repo. It'll work as of tf2vr v1.0.13 - Have fun and dont blow urself up. 

Might make this go a bit further and add a menu toggle for cooking when I get to it.
